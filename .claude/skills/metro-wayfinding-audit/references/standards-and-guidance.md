# Standards & Guidance Register

## How to use this file
- Cite instruments by number and title. **Do not quote clause numbers or numeric thresholds unless the user has supplied the document or the value is listed below as a project parameter to confirm.**
- Tier every reference:
  - `MANDATORY` — only when (a) the instrument is adopted in law, contract or the client's design manual **and** (b) its applicability to this station/asset is established. Record the evidence for both.
  - `BEST PRACTICE` — recognised international/national guidance not shown to be binding here.
  - `PROFESSIONAL OBSERVATION` — consultant judgement, no instrument.
- Editions change. Always write "edition to be confirmed" unless the user supplied the edition.
- Jurisdiction note (Baku Metro): applicable Azerbaijani building, fire-safety, electrical, accessibility and seismic norms, and Baku Metro's own design manual, must be **identified with the client**. Do not name or describe national instruments that have not been provided.
