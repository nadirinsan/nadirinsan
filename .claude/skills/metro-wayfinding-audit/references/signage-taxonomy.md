# Signage Taxonomy & Per-Type Check Lists

Each sign is classified into one primary category (A–D). Combined signs (e.g. station name + exit directions) are classified by primary function and checked against every category they contain.

## A. Directional signage

| Sub-type | Key checks |
|---|---|
| A1 Ceiling-mounted directional | Placed before the decision point; perpendicular to flow; clear headroom; not hidden behind beams/lighting/ads; arrow logic matches geometry from *both* faces if 2-sided |
| A2 Suspended (hanging) | Drop length, sway/vibration from piston-effect airflow, secondary retention, alignment in sequence |
| A3 Wall-mounted directional | Visible along approach (not only when abreast); angle to flow; not competing with advertising |
| A4 Platform direction indicators | Line, terminus/direction name, stations served; visible from platform entry points and along platform |
| A5 Exit direction | Exit numbers/letters + street/destination names; continuity from platform to street |
| A6 Interchange / transfer | Line identity (colour + code + name), direction, continuity to the other line's platform |
| A7 Escalator / lift / stairs direction | Step-free route flagged; lift destinations; "up/down" logic |

Arrow conventions to verify: one arrow set network-wide; arrow position relative to text (arrow on the side it points); up-arrow = straight ahead; down-arrow only where it means "here/below" per the network manual; diagonal arrows used consistently.

## B. Identification signage

| Sub-type | Key checks |
|---|---|
| B1 Station identification (platform name signs, exterior pylons) | Readable from seated position in train at multiple doors; repetition along platform; exterior visibility from approach streets |
| B2 Platform identification | Platform number/letter; line and direction |
| B3 Entrance / exit identification | Exit number at threshold matches directional sequence; exterior identification at street (ID-EXT type) |
| B4 Track / line identification | Line colour, line code (e.g. M3), consistent with network map |
| B5 Facility identification | Toilets, lifts, ticket office, help point, lost property — pictogram + text |

## C. Informational signage

| Sub-type | Key checks |
|---|---|
| C1 Station maps | Orientation ("you are here", map rotated to viewer), exits, lifts, step-free routes |
| C2 Network maps | Current, matches line codes/colours on signs |
| C3 Local area maps | Heads-up orientation, exits, bus/tram stops, landmarks |
| C4 Passenger information panels / totems (e.g. IA-T) | Reading height range, content update mechanism, glare, lighting |
| C5 Timetables / service information | Up to date; dynamic vs static |
| C6 Fare and ticketing | Located before fare line; readable in queue |

## D. Safety & regulatory signage

| Sub-type | Key checks |
|---|---|
| D1 Emergency exits / escape route | Graphical symbols per adopted safety-sign standard; continuity; visibility in emergency lighting / smoke conditions; self- or externally illuminated per adopted rules |
| D2 Fire safety instructions / equipment | Location of extinguishers, hydrants, alarm call points identified |
| D3 Evacuation route plans | Orientation, legend, assembly points |
| D4 Restricted areas | Prohibition signs at staff/track access |
| D5 Safety warnings | Platform edge, escalator safety, mind the gap, hazard markings |
| D6 Accessibility & emergency assistance | Help points, refuge areas, induction loops, assistance contact |

**Separation rule:** safety signage must never be visually dominated or confused by wayfinding or advertising. Mixing safety symbols into commercial or wayfinding panels is a finding.
