# Azerbaijani – English Terminology

Use these terms consistently in AZ, EN and bilingual reports. Keep sign codes (IA-T, SN-C-L-2…), standard numbers, proper names and street names untranslated. Where a source term contains a typo, quote the source verbatim and give the corrected term in brackets.

|---|---|

| Project Background and Scope | Layihənin əsasları və əhatə dairəsi |

| Passenger Journey Assessment | Sərnişin marşrutunun qiymətləndirilməsi |
| Wayfinding Functional Assessment | İstiqamətləndirmənin funksional qiymətləndirilməsi |
| Visual and Graphic Assessment | Vizual və qrafik qiymətləndirmə |

| Accessibility Assessment | Əlçatanlığın qiymətləndirilməsi |
| Identified Gaps and Deficiencies | Aşkar edilmiş boşluqlar və çatışmazlıqlar |
